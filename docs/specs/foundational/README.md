# Foundational behavioral specs

The WHEN/SHALL behavioral specs that drove the FoxyBear CLI build-out (memory,
compaction, consolidation, recall, scheduler, mesh, harness, rebrand) plus an
Effect-migration note. Numbered `00`–`08` with an `INDEX.md`.

**Provenance:** salvaged from the pre-rebaseline `spec/09-daemon` branch
(2026-07-21) before that branch was retired. The *features* these specs describe
were carried into `port/foxybear-v2` during the rebaseline; these documents are
kept as the behavioral record. They predate the dated SDD naming convention
(`yymmdd_project_...`) used by later specs in this directory — treat them as
historical/foundational rather than active work items.

For the current SDD process and the generic pipeline, see the `sdd-workstream`
skill and `FoxyBearOffice/development/sdd/`.
